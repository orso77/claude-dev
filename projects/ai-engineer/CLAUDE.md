# Boolean Master Demo

This repo contains the code and materials for the Boolean Master demo series (3 sessions).

## Key Documents

- [SESSIONS.md](SESSIONS.md) — Overview of all three demo sessions (context, goals, structure)

## Context

- Audience: 1,000–2,000 developers with limited AI experience, attending online
- Format: Live demonstration (not a workshop), ~1.5 hours per session
- Dataset: Kaggle Food Recipes (~13,500 recipes from Epicurious) via Hugging Face
- Session 1: LLM-based structured data extraction
- Session 2: RAG system with vector database
- Session 3: Agentic capabilities with function calling
